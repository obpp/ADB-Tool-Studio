使用说明

一个 adb 小工具合集。网页版用浏览器打开，桌面版是一个常驻托盘的程序， 两边跑的是同一份后端。下面按功能逐个写「什么时候用、怎么用、容易踩什么坑、等价命令」， 页面上的输入框和按钮不重复解释。

全部功能

点卡片直接进对应页面；每个功能的速查紧跟在卡片下面。

通用设置

日志过滤

每个页面的日志框上方有一排按钮：全部 加上 命令 / 信息 / 成功 / 警告 / 失败， 后面是这一类的条数。点一下隐藏这一类，再点恢复。

  • 只切显示，不删日志；关掉期间新来的同类日志也隐藏，但计数照加
  • 选择存在浏览器里，换页面、重开窗口都沿用
  • 一类都不剩时会提示「没有符合当前过滤条件的日志」，不是卡住了

两个状态灯

侧边栏底部两行互不代表：

  • 服务：页面和本地后端通不通，每 3 秒问一次 /api/tools
  • 设备：当前功能看到的 adb 设备。后端常驻 wait-for-device， 上线、掉线即时推送
  • ssh 隧道这类不碰 adb 的页面不显示「设备」那行

全部停止 / 深色

全部停止一次掐掉所有功能的后台任务（ssh 隧道、正在跑的脚本都算）。 深色在浅色/深色之间切换，没手动选过时跟系统走。

循环执行怎么停

脚本执行的循环，点「停止」会立刻打断正在执行的那一轮，或者轮与轮之间的等待； 已经结束的轮次不会被回滚。

桌面版多出来的东西

  • 点 × 关窗口只是收进托盘，后台任务继续跑；真退出要右键托盘「退出」
  • 托盘里可以勾开机自启，也可以「重新加载页面」
  • 只允许开一个实例；端口是系统随机分的，不会撞

日志在哪

桌面版没有控制台，出问题先看日志：

  • exe 旁边 logs\app.log；写不进去时在 %APPDATA%\ADB-Tool-Studio\logs\
  • exe 放在映射网络盘上时，日志和 WebView 缓存都会改用 %LOCALAPPDATA%\ADB-Tool-Studio\
  • 超过 512KB 轮转成 app.log.1

网页版还是桌面版

网页版桌面版
怎么开python3 server.py，自己开浏览器双击 exe
端口固定 8765，被占就起不来系统随机分配
关掉之后服务跟着没了缩进托盘继续跑
开机自启得自己写计划任务托盘里勾一下
同时开两个可以，各跑各的拦住，只留一个

两个版本共用同一份后端和页面，功能完全一样。

常见问题

设备一直出不来，或者显示「未授权」

先在命令行敲一次 adb devices，看设备在不在、状态是不是 device。

常见原因：手机上没打开 USB 调试；插上后手机弹的「允许调试」没点；多台设备同时接着， 这里需要自己选序列号（不选时只有「恰好一台在线」才会自动选）。

脚本一跑就报 : not found

导入时已经自动把 CRLF 换成 LF，所以多半不是换行符的问题，而是脚本里用了设备上没有的东西： 板子上是 toybox 的 sh，没有 bash 语法（[[ ]]、数组、source）， 也没有常用的 GNU 工具。

把脚本开头的 #!/bin/bash 改成 #!/system/bin/sh，或者先手动 adb shell sh 脚本 跑一遍看报错。

反向隧道报 remote port forwarding failed

远程主机上的那个端口已经被别人占了（很常见：远端自己也有 adb server 在听 5037）。 把「远程绑定端口」改一个值，然后在远程主机的 ~/.bashrc 里加：

export ANDROID_ADB_SERVER_PORT=<新的远程绑定端口>

如果是勾了「绑定到 0.0.0.0」才失败，还要确认远端 sshd 开了 GatewayPorts。

页面白屏 / 点什么都没反应

页面每 10 秒给后端发一次心跳、JS 报错也会上报，这些都写进 app.log： 「页面心跳中断」说明页面已经跑不动了，不是接口慢。

桌面版在窗口重新显示、且心跳已经停超过 90 秒时会自动重新加载页面（合盖休眠、拔网线 再回来都属于这种情况），托盘右键也能手动来一次。

如果 exe 是从映射网络盘（比如 Z:）启动的，先把它拷到本机盘再运行 —— 网络一断，WebView2 的缓存跟着掉，画面就会白掉。

exe 被杀毒软件拦下 / 报毒

PyInstaller 打出来的单文件 exe 被误报是常事。可以加白名单，或者用 build.bat dir 打成文件夹模式，体积更小、启动更快、误报也少。
